# 정처기 실기 준비하며 알게 된 다양한 메서드들

### strcat(str1, str2)
<hr />

- 두 문자열을 하나로 합칠 때 사용
- str1 문자열 뒤에 str2 문자열을 연결
- 연결된 문자열(str1)의 포인터를 반환함.

```
char a[11] = "KOREA";
char b[]= "12345";

strcat(a, b)
```

### puts()
<hr />

- 오직 문자열(string)을 출력하기 하는 함수
- 문자열을 출력한 후 자동으로 줄바꿈을 함

### printf()
<hr />

- 문자열 및 다양한 데이터 타입을 서식화 하여 출력하는 함수
- 자동 줄바꿈이 없음

줄 바꿈을 표현할때 puts("")와 printf("\n")을 사용할 수 있다.
